\subsection{Component view}
This section presents the Component view diagram. It outlines the system's main building blocks, their responsibilities, and how they interact.

\begin{figure}[H]
    \centering
    \includegraphics[scale = 0.31]{Architectural_design/uml_diagrams/component_diagram.pdf}
    \caption{Component diagram of the system.}
\end{figure}

\noindent
Each component is explained in detail:
\begin{itemize}
    \item \textbf{Web App}: manages the layout of the website accessed by the users.
    \item \textbf{Controller}: serves as the entry point of the application server, receiving requests from users' web apps and handling them through calls to other system components.
    \item \textbf{Notification Manager}: handles real-time notifications, displaying updates relevant to the user while they interact with the website.
    \item \textbf{Registration Manager}: manages the registration of new users (students, company members, and university members) as well as universities and companies.
    \item \textbf{Login Manager}: oversees user authentication by verifying credentials and generating tokens. These tokens enable user recognition during the requests and are included in every call from the web app.
    \item \textbf{CV Manager}: handles student CVs, both in file format and as digitalized versions.
    \item \textbf{Internship Proposal Manager}: focuses on managing internship proposals published by company members, excluding data related to ongoing internships.
    \item \textbf{Match Manager}: oversees the lifecycle of match proposals, from creation to the communication of final outcomes.
    \item \textbf{Chat Manager}: enables communication between company members and students within the same selection phase through a dedicated chat.
    \item \textbf{Selection Manager}: manages the entire selection process for internship proposals, from scheduling interviews to sharing results with students.
    \item \textbf{Internship Status Manager}: handles all aspects of ongoing internships, including reports, complaints, and feedback.
    \item \textbf{Suggestion Manager}: detects suggestions related to digitalized CVs and internship descriptions.
    \item \textbf{Email Manager}: manages communication with the external email service in order to send emails to registered users.
    \item \textbf{Recommendation Manager}: works with the external statistical analysis tool in order to generate recommendations for students and companies.
    \item \textbf{Interview Scheduler}: coordinates with the external video conferencing tool to schedule interviews, generate meeting links, and facilitate virtual sessions for online interviews.
    \item \textbf{Data Manager}: interacts with the Relational DBMS to perform database operations requested by other components.
\end{itemize}
\subsection{Deployment view}
The Deployment view section illustrates the distribution of system modules across the physical infrastructure, showing how they interact with each other to ensure efficient operation and scalability.

\begin{figure}[H]
    \centering
    \includegraphics[scale = 0.35]{Architectural_design/uml_diagrams/deployment_diagram.png}
    \caption{Deployment diagram of the system.}
\end{figure}

\noindent
Each node is explained in detail:
\begin{itemize}
    \item \textbf{User Device}: the user's device runs a \textbf{Browser} that interacts with the system through HTTPS or WebSocket protocols.
    \item \textbf{Perimeter Firewall}: it acts as a security layer between the user device and the internal system, filtering traffic.
    \item \textbf{Load Balancer}: the \textbf{Load Balancer system} distributes incoming traffic between multiple application servers (including the main server and its replicas) using HTTPS or WebSocket protocols to ensure high availability.
    \item \textbf{Application Servers}: it runs the core application logic, using replicas.
    \item \textbf{Database Cluster}: the \textbf{Database Management System (DBMS)} manages the primary and replica databases (\textbf{Primary DB}, \textbf{Replica 1}, \textbf{Replica 2}). The DBMS handles SQL queries and ensures data replication across the databases.
    \item \textbf{Internal Firewall}: it protects the communication between the application servers and the DBMS, managing the flow of TCP/IP and SQL queries.
\end{itemize}
