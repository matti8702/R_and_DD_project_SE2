\subsubsection{Recommendation Process}

The recommendation process is composed by two main functionality: 
    \begin{itemize}
        \item \textbf{HomePage recommendation :} this function produces suggestions
        , which appears to the user (company or student) in 
        their main page after logging in, without performing any action. The suggestions can include internship proposals 
        for students and CVs that meet the requirements of previously published projects for companies. There is also a notification 
        process associated with this functionality, that sends an email to the user whenever a new recommendation becomes available.

        \item \textbf{Search :} This function can only be performed by a student and provides the results of a search after entering
        a keyword. The results consist of a list of available internship proposals, determined through keyword matching and statistical analysis produced by an external tool. For example, multiple projects with similar keywords might be returned, sorted based on the value derived from the analysis.
        
    \end{itemize}
