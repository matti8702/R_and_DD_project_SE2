# R_and_DD_project_SE2

Repository for the **Software Engineering 2** project (A.Y. 2024/2025), containing the analysis and design documentation for **Students&Companies**, a platform that connects students, companies, and universities for internship management.

## Repository structure

The repository is organized into three main folders:
- `RASD/` → LaTeX sources of the **Requirements Analysis and Specification Document**
- `DD/` → LaTeX sources of the **Design Document**
- `DeliveryFolder/` → final PDF versions and Alloy files submitted for delivery

## Project overview

The **Students&Companies** system supports the whole internship process:
- internship posting by companies,
- student applications,
- recommendation-based matching,
- support for the selection process,
- internship monitoring by the university.

## Available documents

The `DeliveryFolder/` contains the main final deliverables:
- `RASDv1.pdf`
- `RASDv2.pdf`
- `DDv1.pdf`
- `RASD-Alloy.als`

## Technologies

- **LaTeX** for document writing
- **Alloy** for formal analysis of part of the system
