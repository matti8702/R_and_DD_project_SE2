\subsection{Functional Requirements}

\begin{listInSquareBrackets}{R}
    %we thought that student look for an internship in two methods: 1 search by keyword 2 use recommendation (which appears in home page)
    %convert all in must, should 

    \item The system must permit students to register by providing their personal information and an institutional email.\footnote{"Institutional email" stand for the email assigned to the student by their university.}
    \item The system must permit companies to register.
    \item The system must permit universities to register.
    \item The system must allow users to log in by inserting their credentials.
    \item The system must allow student to publish his CV.
    \item The system must allow companies to publish internships.
    \item The system shall inform students when suitable internships are available through recommendation.
    \item The system shall inform companies about the availability of student CVs corresponding to their needs, through recommendation.
    \item The system must use analysis produced by the statistical analysis tool to formulate recommendation for students and companies.
    \item The system shall provide suggestions to companies for the project description.
    \item The system shall provide suggestions to students regarding their CVs.
    \item The system shall allow the company to select the students, among all candidates, for the internship.
    \item The system must collect feedbacks from students and companies in order to keep statistics up-to-date.
    \item The system must send feedbacks to the statistical analysis tool in order to update its analysis.
    \item The system must allow the student and the company to monitor the execution and the outcome of the matchmaking process.
    \item The system must allow the student, the company and the university to monitor the ongoing internship.\footnote{The monitoring is achieved through report visualization.}
    \item The system must allow interrupting an internship when university requires it.\footnote{Only the university could interrupt the internship and not the company.}
    \item The system must provide to student all available internships related to the keyword specified by him.
    \item The system shall inform the company and the student that the internship has concluded cause of the decision of the student's university.
    \item The system must prevent students to apply for the internship once the company has selected the eligible candidate for it.
    \item The system shall allow students to modify their CV.
    \item The system shall allow companies to modify internship description.
    \item The system must allow students and companies (that are involved in the same internship) to send messages to each other.
    \item The system must allow students and companies to posts reports regarding internship.
    \item The system must notify the company about the new matching proposal made by the student.
    \item The system shall allow the student to send a matching proposal to a company.
    \item The system must inform the student about a new matching proposal made by the company.
    \item The system must inform the student or the company of the outcome of the matching proposal he sent to the counterpart.
    \item The system shall allow the company or the student to either accept or decline the matching proposal made by the counterpart.
    \item The system must allow future members of the company to add their company to the application by providing a name, a description and a mail domain.
    \item The system must allow future members of the university to add their university to the application by providing a name and a mail domain.
\end{listInSquareBrackets}

\usecase
{
    Registration of a university member
}
{
    University member and eMail provider
}
{
    The university member clicks on button \textit{"Register as a university member"}.
}
{
    \begin{enumerate}
        \item The system shows the \textit{"Registration form"}.
        \item The university member enters his name, surname and date of birth, a password and his institutional email.
        \item The university member selects his university amoung all the universities registered to the system.
        \item The university member clicks the button \textit{"Register"}.
        \item The system verifies that the email is associated to the university provided.
        \item The system verifies that the email is not already registered to the system.
        \item The system sends an email to the university member by an eMail provider.
    \end{enumerate}
}
{
    The university member verifies the email provided to the system by following the instructions on the email message that he received.
}
{
    \begin{itemize}
        \item The email is already registered to the system. The system will show an error message \textit{"User already registered"} and it will interrupt the registration process.
        \item The email provided is not linked to the university provided by the member. In this case the system will show an error message \textit{"Invalid email domain"}.
        \item The university in which the university member works is not present in the system. In this case the university member clicks the button \textit{"Create your university"} and by clicking it the system will show the \textit{"University registration form"} in which the university member will enter all the information regarding the university. Once he has confirmed all data, the institution will be inserted to the system and moreover it will sends a confirmation email to the university member.
        \item The member does not confirm their email address within one day of entering the data into the system. In this case the system will delete all provided data. The member will then need to repeat the registration process.
    \end{itemize}
}

    The student or company member is logged into the platform's homepage. 
    The internship is ended.
}
{
    \begin{enumerate}
        \item The user notices the system notification indicating the end of the internship.
        \item The user clicks on the notification.
        \item The system prompts the user with the message \textit{"Would you like to write a feedback?"} and provides \textit{"Yes"} and \textit{"No"} options.
        \item If the user selects \textit{"No"}, the system stops the notification from appearing.
        \item If the user selects \textit{"Yes"}, the system redirects them to the feedback page.
        \item The user writes a comment and rates the internship experience.
        \item The user clicks the \textit{"Post"} button to submit the feedback.
        \item The system processes and forwards the feedback to the relevant external tool.
    \end{enumerate}

}
